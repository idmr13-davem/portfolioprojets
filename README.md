# Portfolio V3 — GitHub Pages

Static release for davidmontealegreux.com: Home, four case studies (Registro ML, Motion Level, Accounts for minors in Mexico, Switching accounts across countries), the Ropstar and Winefast side projects, three articles, 404 and page under work. about.html redirects to the About section of the Home.

Copy this folder's contents into the publishing branch root, with index.html, CNAME and .nojekyll at the root. Replace the old publishing tree rather than overlaying files, so obsolete V2 files do not survive. Do not upload the ZIP itself or the outer releases folder.

No build or server is required. English pages sit at the root and Spanish pages under es/, each with its content already in the HTML (JavaScript adds the interactions). Analytics loads only on the production domain and only after consent.

Prepared from local working files by scripts/prepare-github-pages-v3.py; this package is not evidence of employer content approval. No deployment was performed.
